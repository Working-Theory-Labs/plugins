# SalesSmyth plugins

This is the catalog Claude reads to install SalesSmyth's plugins. It lists one plugin today.

| Plugin | What it is for |
|---|---|
| `positionary` | A brand's words, site, look, promotion and studies, worked from the record held in its site's Admin |

## Install

In Claude Code:

```
/plugin marketplace add working-theory-labs/plugins
/plugin install positionary@working-theory
```

On claude.ai, download `positionary.zip` from this repository's latest release and upload it under Plugins.

## What you need

A Working Theory site, and a sign-in to its Admin. The plugin holds the list of commands. Each command's method is served by your site's Admin when you run it, to a workspace that has the command's pack.
